# save_credentials

Helper that opens .Renviron file for storing credentials. Deprecated:
only used to support other deprecated exported functions like
[`pull_smartabase()`](https://teamworksapp.github.io/smartabaseR/reference/pull_smartabase.md)
and
[`push_smartabase()`](https://teamworksapp.github.io/smartabaseR/reference/push_smartabase.md)

## Usage

``` r
save_credentials()
```

## Value

.Renviron

## Examples

``` r
if (FALSE) { # \dontrun{
save_credentials()
} # }
```
