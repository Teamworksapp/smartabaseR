# Export Smartabase group data

This function uses the Smartabase API to export the names of the
Smartabase groups that the logged in user has access to.

For more details see the help vignette:
[`vignette("helper-functions")`](https://teamworksapp.github.io/smartabaseR/articles/helper-functions.md)

## Usage

``` r
sb_get_group(url, username, password, ..., option = sb_get_group_option())
```

## Arguments

- url:

  Smartabase url; e.g. 'example.smartabase.com/site'

- username:

  Smartabase username

- password:

  Smartabase password

- ...:

  These dots are for future extensions and must be empty

- option:

  More options generated by a
  [`sb_get_user_option()`](https://teamworksapp.github.io/smartabaseR/reference/sb_get_user_option.md)
  object

## Value

A tibble containing Smartabase group data

## Options

There are also a range extra options than can be supplied to the
`option` argument. In order to reduce argument clutter in
`sb_get_group()`, all options must be generated by the
[`sb_get_group_option()`](https://teamworksapp.github.io/smartabaseR/reference/sb_get_group_option.md)
function. Please see
[`sb_get_group_option()`](https://teamworksapp.github.io/smartabaseR/reference/sb_get_group_option.md)
for more details.

## Examples

``` r
if (FALSE) { # \dontrun{
# Get user ID data:
group_data <- sb_get_group(
  url = "example.smartabase.com/site",
  username = "example.user",
  password = "examplePassword"
)
} # }
```
