# Upsert profile data

`sb_upsert_profile()` imports data frame into a Smartabase event form
using the Smartabase API. It requires the user to input a data frame, a
valid Smartabase event form name, url and credentials.

If the data frame contains a profile record that already exists in
Smartabase, then that profile record is updated. If the data frame
contains a profile record that does not exist in Smartabase, then that
profile record will be inserted as a new profile record.

For more details see the help vignette:
[`vignette("importing-data")`](https://teamworksapp.github.io/smartabaseR/articles/importing-data.md)

## Usage

``` r
sb_upsert_profile(
  df,
  form,
  url,
  username,
  password,
  ...,
  option = sb_upsert_profile_option()
)
```

## Arguments

- df:

  Data to be imported to Smartabase

- form:

  Name of Smartabase event form

- url:

  Smartabase url e.g. "example.smartabase.com/site"

- username:

  Smartabase username

- password:

  Smartabase password

- ...:

  These dots are for future extensions and must be empty

- option:

  More options accessible via
  [`sb_upsert_profile_option()`](https://teamworksapp.github.io/smartabaseR/reference/sb_upsert_profile_option.md)
  object

## Value

Data frame with extra details about import status

## Options

There are also a range extra options than can be supplied to the
`option` argument, including options for setting a different ID column
and supplying the names of table fields, among others. In order to
reduce argument clutter in `sb_upsert_profile()`, all options must be
generated by the
[`sb_upsert_profile_option()`](https://teamworksapp.github.io/smartabaseR/reference/sb_upsert_profile_option.md)
function. Please see
[`sb_upsert_profile_option()`](https://teamworksapp.github.io/smartabaseR/reference/sb_upsert_profile_option.md)
for more details.
